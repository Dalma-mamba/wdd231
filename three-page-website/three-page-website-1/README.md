# Three-Page Website

## Overview
This project is a simple three-page website consisting of an index page, an about page, and a contact page. The website is designed with accessibility and responsiveness in mind, utilizing semantic HTML, CSS for styling, and JavaScript for interactivity.

## Purpose
The purpose of this website is to provide users with information about the project, a way to contact the developers, and a demonstration of the website's features through a video link.

## Project Structure
```
three-page-website
├── index.html       # Landing page of the website
├── about.html       # Information about the website's purpose
├── contact.html     # Contact form for user inquiries
├── css
│   └── styles.css   # Styles for the website
├── js
│   └── main.js      # JavaScript functionality for the website
└── README.md        # Documentation for the project
```

## Setup Instructions
1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the landing page.
3. Navigate to the about and contact pages using the navigation links provided.

## Usage
- The **index.html** page serves as the main entry point and includes links to the other pages.
- The **about.html** page provides details about the website's purpose and features.
- The **contact.html** page contains a form for users to submit inquiries. Upon submission, the data will be processed and displayed on a separate action page.

## Features
- Responsive design that adapts to various screen sizes.
- Semantic HTML for better accessibility and SEO.
- JavaScript functionality for dynamic content and user interaction.

## Video Demonstration
A video demonstration of the website's features can be found in the footer of each page.
